# Crescendo
---
Crescendo is a Discord bot for music lovers. It is supposed to create audio files on command.
Crescendo uses an easy to understand notation (explaned [here](https://github.com/josocwill/Crescendo-Discord-bot/wiki/Tune-notation)) which supports rests, irregular timing, chromatic scales, polyphony and different sound waves, all of this, from your discord.
