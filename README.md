# Crescendo
---
Crescendo is a Discord bot for music lovers. It is supposed to create audio files on command.
Crescendo uses an easy to understand notation (explained [here](https://github.com/josocwill/Crescendo-Discord-bot/wiki/Tune-notation)) which supports rests, irregular timing, chromatic scales, polyphony and different sound waves, all of this, from your discord.

Use Crescendo yourself by using this [invite link](https://discord.com/oauth2/authorize?client_id=1564361193970212895) or in a server channel with [this one](https://discord.gg/4pM94DXrUe)!
